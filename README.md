## 二、如何本地预览原型

**方式一：可点击演示（推荐）**

直接双击 `prototype/index.html`，用浏览器打开。鼠标划过页面会出现绿色热区，点击即可跳转页面，左下角有当前页面的说明。

**方式二：原型总览截图**

双击 `prototype/overview.html`，7 个页面并排显示，用于截一张总览图放进博客。

**方式三：直接看图片**

`prototype/png/` 里是 7 张 750×1624 的效果图，可以直接拖进博客编辑器上传。

## 三、原型在线链接

**🔗 <https://majestic-macaron-f0347e.netlify.app/>**

链接指向 `prototype/` 目录，也就是 `prototype/index.html` 的在线版本：绿色热区可点击跳转，左下角显示当前页面说明。页面跳转关系表见 `docs/04-页面说明.md` 最后一节。

### 如何更新线上原型

1. 改 `tools/gen_prototype.py`（配色在文件顶部 `C = dict(...)`，文案在各 `page_xxx()` 函数里）；
2. 重新生成 SVG / PNG：
   ```bash
   python tools/gen_prototype.py
   node tools/render_png.js
   ```
3. 把 `prototype/` 整个目录拖到 <https://app.netlify.com/drop> 重新部署（登录后站点会保留，不会每次生成新地址）；
4. 站点主地址 `https://majestic-macaron-f0347e.netlify.app/` 不变，刷新即可看到新版本。

> ⚠️ Netlify 每次部署还会额外生成一个带哈希的**单次部署地址**，形如
> `https://<deploy-id>--majestic-macaron-f0347e.netlify.app/`。
> 那个地址只对应当前这一次部署，重新部署后可能失效，**不要写进博客或作业文档**。

## 四、需要下载什么工具？

| 工具 | 是否必须 | 说明 |
| --- | --- | --- |
| **浏览器**（Edge / Chrome） | ✅ 必须 | 预览原型，无需下载 |
| **Netlify** | ✅ 必须 | 托管原型在线链接，**网页版，无需下载**，免费注册即可 |
| Python 3 | ⬜ 可选 | 只有在你要**重新生成原型**时才需要（本机已装 3.9.13） |
| Node.js | ⬜ 可选 | 只有在你要**重新导出 PNG** 时才需要（本机已装 v24.21.0） |

**结论：除了浏览器，你不需要下载任何东西。**

## 五、如何重新生成原型（改文案 / 改配色）

如果你不满意某段文案或颜色，改脚本比在工具里一个个改更快：

```bash
# 1. 改 tools/gen_prototype.py 里的文案或配色
#    配色集中在文件顶部 C = dict(...) 里
#    页面文案在各 page_xxx() 函数里

# 2. 重新生成 SVG
python tools/gen_prototype.py

# 3. 重新导出 PNG（可选）
node tools/render_png.js
```

流程图同理：

```bash
python tools/gen_flowchart.py
```
