## 二、如何本地预览原型

**方式一：可点击演示（推荐）**

直接双击 `prototype/index.html`，用浏览器打开。鼠标划过页面会出现绿色热区，点击即可跳转页面，左下角有当前页面的说明。

**方式二：原型总览截图**

双击 `prototype/overview.html`，7 个页面并排显示，用于截一张总览图放进博客。

**方式三：直接看图片**

`prototype/png/` 里是 7 张 750×1624 的效果图，可以直接拖进博客编辑器上传。

## 三、如何生成原型在线链接（作业要求的"在线链接"）

作业要求原型必须用**专用原型设计工具**实现并给出**在线链接**。本项目选用的工具是 **即时设计**。

### 第 1 步：注册即时设计

打开 <https://js.design> ，用手机号或微信注册（免费，国内直连，不需要梯子）。

### 第 2 步：新建文件并导入 SVG

1. 进入工作台 → 「新建文件」→ 选择「移动端」尺寸（或自定义 375 × 812）。
2. 把 `prototype/svg/` 里的 **7 个 SVG 文件全选，直接拖进画布**。
   - 导入后每个页面会成为一个画板（Frame）。
   - SVG 里的文字、矩形都是**独立可编辑图层**，可以自由改颜色、改文案。
3. 建议把 7 个画板横向排开，并加上页面名称标注。

### 第 3 步：加上页面跳转交互（可选，但很加分）

在即时设计右侧「交互」面板中：

| 在哪个页面 | 点哪个元素 | 跳转到 |
| --- | --- | --- |
| 01 首页 | 搜索框 | 04 搜索页 |
| 01 首页 | 任意信息卡片 | 06 信息详情 |
| 01 首页 | 底部「发布」 | 02 发布信息 |
| 01 首页 | 底部「我的」 | 07 我的发布 |
| 02 发布信息 | 「立即发布」 | 03 发布成功 |
| 03 发布成功 | 「查看我的发布」 | 07 我的发布 |
| 04 搜索页 | 搜索框 / 历史词 / 热词 | 05 搜索结果 |
| 05 搜索结果 | 任意结果卡片 | 06 信息详情 |
| 07 我的发布 | 任意卡片 | 06 信息详情 |

> 完整的跳转关系表见 `docs/04-页面说明.md` 最后一节。

### 第 4 步：生成分享链接

点右上角「分享」→ 把权限设为「**任何人可查看**」→ 复制链接。

把链接填到博客里的 **🔗 原型在线链接** 位置。

### 如果即时设计导入 SVG 有问题？

备选方案：

- **用 PNG 代替**：把 `prototype/png/` 里的 7 张图拖进即时设计，作为图片放在画板上（图层不可编辑，但能生成在线链接，应付作业足够）。
- **换 Figma**：Figma 对 SVG 的支持最好，拖动导入即可，但国内访问 figma.com 可能不稳定。
- **换墨刀**（<https://modao.cc>）：只支持导入图片，用 `prototype/png/` 里的 PNG。

## 四、需要下载什么工具？

| 工具 | 是否必须 | 说明 |
| --- | --- | --- |
| **浏览器**（Edge / Chrome） | ✅ 必须 | 预览原型，无需下载 |
| **即时设计** | ✅ 必须 | **网页版，无需下载**，注册即可用 |
| Python 3 | ⬜ 可选 | 只有在你要**重新生成原型**时才需要（本机已装 3.9.13） |
| Node.js | ⬜ 可选 | 只有在你要**重新导出 PNG** 时才需要（本机已装 v24.21.0） |

**结论：除了浏览器，你不需要下载任何东西。**

## 五、如何重新生成原型（改文案 / 改配色）

如果你不满意某段文案或颜色，改脚本比在工具里一个个改更快：

```bash
# 1. 改 tools/gen_prototype.py 里的文案或配色
#    配色集中在文件顶部 C = dict(...) 里
#    页面文案在各 page_xxx() 函数里

# 2. 重新生成 SVG
python tools/gen_prototype.py

# 3. 重新导出 PNG（可选）
node tools/render_png.js
```

流程图同理：

```bash
python tools/gen_flowchart.py
```
