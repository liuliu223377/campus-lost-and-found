## 二、如何本地预览原型

**方式一：可点击演示（推荐）**

直接双击 `prototype/index.html`，用浏览器打开。鼠标划过页面会出现绿色热区，点击即可跳转页面，左下角有当前页面的说明。

**方式二：原型总览截图**

双击 `prototype/overview.html`，7 个页面并排显示，用于截一张总览图放进博客。

**方式三：直接看图片**

`prototype/png/` 里是 7 张 750×1624 的效果图，可以直接拖进博客编辑器上传。

## 三、如何用墨刀生成原型在线链接

作业要求原型必须用**专用原型设计工具**实现并给出**在线链接**。本项目选用的工具是 **墨刀**（<https://modao.cc>，国内直连、网页版免安装）。

### 第 1 步：注册墨刀

打开 <https://modao.cc> ，手机号注册（免费版够用）。

> ⚠️ 免费版有两个限制要留意：**自定义分享链接只有 1 个**（别浪费），**单张图片上限 2MB**（`prototype/png/` 里的图 50–100KB，远没到）。

### 第 2 步：新建项目并导入 7 张页面图

1. 新建项目 → 选「移动端」→ 画板尺寸 **375 × 812**。
2. 把 `prototype/png/` 里的 7 张图（750 × 1624 的 2 倍图）逐页拖入，每页一张、撑满画板。
3. 按文件名给页面命名：`01 首页`、`02 发布信息`、`03 发布成功`、`04 搜索页`、`05 搜索结果`、`06 信息详情`、`07 我的发布`。

> 墨刀不直接支持导入 SVG（官方只列了 Axure / Sketch / Figma / PS），所以走 PNG。SVG 源文件留在 `prototype/svg/` 备用。

### 第 3 步：按坐标表加热区交互

在墨刀里：选中要点击的组件 → 右侧【交互】→【添加交互】→ 触发方式【单击】→ 行为【跳转页面】→ 选目标页面。

### 第 4 步：发布并生成分享链接

1. 右上角【分享】/【发布】→ 勾选**启用演示模式**；
2. 权限选**公开链接**（"互联网上获得链接的人可查看"），生成链接后复制；
   - 这样老师**不用注册墨刀账号**就能点开看带跳转的演示；
   - 别设成"企业成员可查看"或加密码，否则外部打不开。
3. 把链接填到 `blog/结对作业1-….md` 的 **🔗 原型在线链接** 处（本 README 的 A3 那条）。

> ⚠️ 发布之后如果又改了页面结构或交互，**要重新点一次「更新发布」**，否则分享链接里还是旧版本。

### 原型改版了怎么办

改了 `tools/gen_prototype.py` 里的文案或配色后：

```bash
python tools/gen_prototype.py   # 重新生成 7 个页面 SVG
node tools/render_png.js        # 重新导出 PNG
```

再把新的 PNG 在墨刀里替换一遍即可。

### 关于仓库里那个 HTML 原型

`prototype/index.html` 是同一套页面图的**本地可点击演示**（双击就能开），当初是为了快速验证跳转关系做的，热区坐标也就是上面那张表的来源。它**不作为作业提交的在线链接**，正式链接以墨刀为准。

## 四、需要下载什么工具？

| 工具 | 是否必须 | 说明 |
| --- | --- | --- |
| **浏览器**（Edge / Chrome） | ✅ 必须 | 预览原型，无需下载 |
| **墨刀**（<https://modao.cc>） | ✅ 必须 | **网页版，无需下载**，免费注册即可；用它做原型并生成在线链接 |
| Python 3 | ⬜ 可选 | 只有在你要**重新生成原型**时才需要（本机已装 3.9.13） |
| Node.js | ⬜ 可选 | 只有在你要**重新导出 PNG** 时才需要（本机已装 v24.21.0） |

**结论：除了浏览器，你不需要下载任何东西。**

## 五、如何重新生成原型（改文案 / 改配色）

如果你不满意某段文案或颜色，改脚本比在工具里一个个改更快：

```bash
# 1. 改 tools/gen_prototype.py 里的文案或配色
#    配色集中在文件顶部 C = dict(...) 里
#    页面文案在各 page_xxx() 函数里

# 2. 重新生成 SVG
python tools/gen_prototype.py

# 3. 重新导出 PNG（可选）
node tools/render_png.js
```

流程图同理：

```bash
python tools/gen_flowchart.py
```
