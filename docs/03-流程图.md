## 一、总体使用流程

```mermaid
flowchart TD
    A([打开小程序]) --> B[首页：信息列表]
    B --> C{我想做什么？}
    C -->|随便看看| D[浏览信息列表]
    C -->|找特定物品| E[搜索关键词]
    C -->|我有东西要发| F[点击「发布」]
    D --> G[查看物品详情]
    E --> E1[搜索结果列表] --> G
    F --> H[填写物品信息] --> I[点击「立即发布」] --> J([发布成功])
    J --> K[我的发布]
    G --> L[联系发布者]
    L --> M([复制微信号 · 到微信添加好友])
    K --> N[修改信息状态]
    N --> O([标记为已解决 · 自动下架])
```

## 二、流程一：查看信息 → 查看详情 → 联系发布者

```mermaid
flowchart LR
    A[进入首页] --> B[浏览或搜索信息]
    B --> C[查看物品详情]
    C --> D[联系发布者]
    D --> E([复制微信号<br/>到微信添加好友])
```

## 三、流程二：发布信息 → 发布成功

```mermaid
flowchart LR
    A[点击「发布」] --> B[填写物品信息]
    B --> C[点击「立即发布」]
    C --> D{信息是否完整？}
    D -->|否| B
    D -->|是| E[发布成功]
    E --> F[查看我的发布]
```

**填写物品信息**包含以下字段：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 类型（寻物 / 招领） | ✅ | 表单顶部先选，决定信息归类 |
| 物品照片 | ⭕ 选填 | 最多 1 张，有照片的信息更容易被认出来 |
| 物品名称 | ✅ | 用于搜索匹配的核心字段 |
| 物品分类 | ✅ | 证件卡类 / 钥匙 / 雨伞 / 水杯 / 耳机 / 图书 |
| 地点与时间 | ✅ | 丢失或拾取的地点、时间 |
| 详细描述 | ⭕ 选填 | 颜色、品牌、有无挂件等特征，限 100 字 |
| 联系方式 | ✅ | 微信号或手机号，仅详情页可见 |

## 四、流程三：搜索物品 → 查看搜索结果

```mermaid
flowchart LR
    A[点击搜索框] --> B[输入物品关键词]
    B --> C[查看搜索结果]
    C --> D{有匹配结果？}
    D -->|否| E[提示：换个关键词试试]
    D -->|是| F[查看物品详情]
    F --> G[联系发布者]
```

## 五、信息状态流转

```mermaid
stateDiagram-v2
    [*] --> 招领中: 发布「招领」信息
    [*] --> 寻物中: 发布「寻物」信息
    招领中 --> 已解决: 发布者标记为已解决
    寻物中 --> 已解决: 发布者标记为已解决
    已解决 --> [*]: 自动下架，不再出现在首页与搜索结果中
```

**设计说明**：物品归还后，信息如果继续挂在首页，会浪费其他同学的时间，也会降低整个平台的可信度。因此详情页底部为发布者提供"标记为已解决"入口，标记后信息自动下架，只保留在"我的发布"中可查。

## 六、页面跳转关系

```mermaid
flowchart TD
    H[01 首页] -->|点击搜索框| S[04 搜索页]
    H -->|点击信息卡片| D[06 信息详情]
    H -->|底部「发布」| P[02 发布信息]
    H -->|底部「我的」| M[07 我的发布]
    S -->|输入并搜索| R[05 搜索结果]
    R -->|点击结果卡片| D
    P -->|点击「立即发布」| OK[03 发布成功]
    OK -->|查看我的发布| M
    OK -->|返回首页| H
    M -->|点击卡片| D
    M -->|标记为已解决| M
    D -->|联系 TA| W([复制微信号])
```
